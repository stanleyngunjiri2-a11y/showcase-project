# Personal Project Showcase

## Description

This is a React application that allows users to view, search, and add projects. The application displays a list of project cards, each containing an image, title, and description. Users can also add new projects through a form and search for projects using the search bar.

## Features

- Display a list of projects
- Add a new project
- Search projects by title or description
- Responsive design for different screen sizes
- Built using reusable React components

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Installation

1. Clone the repository

```bash
git clone <repository-link>
```

2. Navigate into the project folder

```bash
cd portfolio-platform
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
